# CCR: UI Asset Slice Insets

Status: Superseded by
[`ui-asset-scope-cleanup.md`](ui-asset-scope-cleanup.md).

This request previously proposed public slice inset metadata for nine-slice
frame textures. The proposal is no longer active. Public contracts no longer
carry UI asset binding or nine-slice rendering metadata, and surface-specific
frame rendering stays in app-local surface code until a complete shared renderer
is introduced through a new CCR.
